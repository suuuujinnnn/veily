# VEILY Wedding Planner Mockup

웨딩 플래너와 신랑·신부가 일정, 체크리스트, 업체 추천과 계약 정보를 함께 관리하는 인터랙티브 프론트엔드 목업입니다.

## 실행

```powershell
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 상태 로직 테스트는 `npm test`로 실행합니다.

플래너 화면은 `/`, 고객 포털은 `/portal/c1`에서 확인할 수 있습니다. 실제 인증, 백엔드, AI·지도 API는 사용하지 않으며 새로고침하면 데모 데이터가 초기화됩니다.
