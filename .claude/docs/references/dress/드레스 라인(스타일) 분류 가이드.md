1. A라인 (A-Line)
상체는 슬림하게 잡아주고, 허리부터 자연스럽게 퍼지는 가장 기본 라인. 알파벳 A 형태로 퍼지는 실루엣이 특징이에요.

✔ A라인 특징
부담 없이 누구나 잘 어울리는 라인

우아하고 정석적인 웨딩드레스 분위기

허리 스커트 라인이 자연스레 퍼져서 깔끔한 실루엣

임신 초기 신부 → 배가 거의 드러나지 않아 선호도가 높아요

‍

✔ 이런 신부님께 추천해요
체형 상관없이 무난하게 잘 어울리는 드레스를 찾는 신부

전체적인 체형 커버하고 싶은 신부

어깨나 팔뚝이 고민일 때 반팔+A라인 추천해요

2. 벨라인 (Ball Gown / Princess Line)
허리는 꽉 잡고, 스커트 라인이 풍성하게 퍼지는 라인.
공주풍 드레스 하면 떠오르는 바로 그 실루엣이에요.

✔ 벨라인 특징
하체를 완벽하게 커버해주는 라인

웅장하고 화려한 분위기 연출

결혼식장 입장 장면에서 존재감 UP

‍

✔ 이런 신부님께 추천
하체비만 컴플렉스가 있을 때 (허벅지·힙 커버)

허리가 잘록한 신부는 더 잘 어울려요!

화려한 스타일+볼륨감있는 드레스를 좋아하는 신부님에게 추천해요

3. 머메이드 라인 (Mermaid)
슬림 드레스의 대표적인 드레스라인이에요.
무릎 위까지 몸에 타이트하게 붙다가 무릎 아래에서 인어 꼬리처럼 퍼지는 실루엣이 매력적. 시크·고급스러운 분위기 연출. 시크·고급·럭셔리 스타일 좋아하는 경우 잘 어울려요.

✔머메이드 특징
바디라인이 정직하게 드러나는 라인이에요

시크·고급스러운 분위기 연출

피팅 시 ‘와…’ 하는 감탄이 절로 나오는 실루엣이에요

‍

✔ 이런 신부님께 추천
상체가 날씬하고, 골반·허리 라인이 예쁜 신부

롱다리·큰 키, 모델핏 신부님에게 추천

시크·고급·럭셔리 스타일 좋아하는 경우 잘 어울려요

4. 엠파이어 라인 (Empire Line)
가슴 바로 아래에서부터 자연스럽게 일자로 떨어지는 라인이에요.
로맨틱하고 여리여리한 분위기로 여신분위기를 자아내요.
내추럴·감성적인 하우스웨딩에 찰떡이에요.

✔ 엠파이어 라인 특징
허리선을 가슴 바로 아래에 둬 다리가 길어 보임

머메이드라인과 비교했을때 가볍고 움직임이 편해요

내추럴·감성적인 하우스웨딩에 찰떡이에요

머메이드 드레스: 목선이 드러나는 깔끔한 로우 번이나 슬릭 포니테일 추천. 몸매를 살리는 드레스 특성상 정돈된 헤어스타일이 전체적인 세련됨을 더해줍니다. 곡선미를 강조한 만큼, 너무 복잡하지 않은 깔끔한 스타일이 잘 어울려요.
벨라인 드레스: 허리를 강조하고 풍성한 스커트가 특징인 벨라인에는 클래식 업스타일이 찰떡입니다. 티아라와 롱 베일을 더하면 입장할 때부터 시선을 한 몸에 받는 ‘공주님’ 느낌 완성! 드레스가 워낙 드라마틱한 만큼 헤어도 고전적인 우아함을 잃지 않아야 해요.
모던 미니멀 드레스: 최근 트렌드인 모던 미니멀 스타일은 머리카락 한 올 흐트러지지 않은 슬릭 백 헤어가 가장 잘 어울려요. 장식 없이 깔끔한 드레스에 맞춰 헤어도 군더더기 없이 정돈하는 게 핵심입니다. 작은 액세서리 하나로 포인트를 주면 전체 밸런스가 딱 맞아요.
엠파이어 드레스: 감성적이고 여리여리한 분위기를 원하는 신부님께는 루즈한 웨이브나 자연스러운 반묶음 헤어를 추천합니다. 드레스의 부드러운 라인과 잘 어우러져서 여성스러운 분위기를 한층 더 살려주거든요.
A라인 드레스: 안정적인 기본 실루엣인 A라인은 사실 어떤 헤어와도 잘 어울리는 만능 스타일입니다. 다만, 부케나 귀걸이, 면사포 등 소품으로 전체적인 조화를 맞추는 센스가 필요해요.
