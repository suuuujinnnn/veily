## 1. 드레스 (Dress)

### 1-1. 라인(실루엣)
A 라인, 벨 라인, 머메이드 라인, 엠파이어 라인, H 라인, 프린세스 라인, 모던 미니멀

### 1-2. 트레인(길이)
롱 트레인, 쇼트 트레인

### 1-3. 소재(원단)
튤, 레이스, 미카도 실크, 새틴 실크, 도비 실크, 오간자(오간자 실크), 시폰, 타프타

### 1-4. 장식 디테일
굵은 비즈(볼드 비딩), 맑은 비즈(잔잔 비즈), 비딩 일반

> 참고: 원본 키워드 목록에는 `레이스`·`미카도 실크`가 중복 등록되어 있어 위에서는 1회로 정리했고,
> 포괄어인 `실크`는 실크 계열(미카도/새틴/도비)의 상위 개념이므로 하위 항목으로 분리했습니다.

## 정리 시 남은 판단 포인트

- **드레스**: `실크`처럼 상위 개념 키워드를 태그로 노출할지, 세부 소재만 노출할지 결정 필요.
- **메이크업**: `강하게`, `깔끔`은 다른 키워드(글램, 투명)와 의미가 겹칩니다. 통합 여부 검토.
- **스튜디오**: 무드 키워드가 24개로 가장 많습니다. 사용자 필터로 쓰려면 8~10개 수준으로 압축 권장.
- **스튜디오 씬**: `롯데타워씬`처럼 특정 업체 종속 키워드는 별도 그룹(업체 고유 씬)으로 분리 검토.
- **공통**: `초록초록`, `자연광`은 스튜디오·웨딩홀에 중복 등장 → 카테고리 공통 태그로 승격 가능.
